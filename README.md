# Python 聚餐費用試算器

## 基本資料

- 姓名：請填入自己的姓名
- 學號：請填入自己的學號

## 程式用途

本程式用來計算聚餐費用，包含餐費、服務費、折價券及每人分攤金額，並判斷是否超過每人預算。

## 使用的 Python 語法

- 變數
- 字串方法 strip()、lower()、replace()
- 型別轉換 int()、float()
- 數字運算
- 布林比較
- f-string

## 三組測試結果

| 測試 | 人數 | 折價券 | 應付總額 | 每人費用 | 是否超過預算 |
|---|---:|---:|---:|---:|---|
| 第一組 | 4 | 100元 | 1220元 | 305元 | True |
| 第二組 | 5 | 100元 | 1220元 | 244元 | False |
| 第三組 | 4 | 220元 | 1100元 | 275元 | False |

## 問題回答

### 問題一：為什麼 "4" 要先轉成數字？

因為 "4" 是字串，不能直接拿來進行數學除法，所以要使用 int() 將它轉換成整數 4，才能計算每個人要分攤的費用。

### 問題二：如果先扣折價券，再計算服務費？

第一組先扣除100元折價券，餐費變成1100元，再計算10%服務費為110元，最後應付總額為1210元。
